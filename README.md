# 🌿 Olhos da Amazônia

A modern and responsive website created to showcase the **Amazon Rainforest**, its incredible biodiversity, wildlife, curiosities, and the importance of environmental preservation.

## 📖 About the Project

**Olhos da Amazônia** is a web project developed as part of a college assignment. The main goal is to create an interactive and visually engaging experience while presenting information about one of the most important ecosystems on Earth.

The website combines educational content with a modern interface to encourage people to learn more about the Amazon and the importance of protecting it.

## ✨ Features

* 🌱 Information about the Amazon Rainforest
* 🐆 Wildlife and biodiversity section
* 📊 Interesting facts and statistics
* 🖼️ Interactive image gallery
* 🔍 Image zoom/lightbox
* 🗺️ Amazon-related map section
* 📱 Responsive design for mobile and desktop
* 🎨 Modern and clean user interface
* ✨ Interactive animations and effects
* 📩 Contact form
